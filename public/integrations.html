Apple Calendar Integration

✅ Available Now Blue Badge

Two-way synchronization between Aurely reminders and Apple Calendar events. Create reminders in Aurely and they appear in your calendar, or import calendar events into Aurely.

Features

Two-Way Sync
Sync reminders to calendar and import events from calendar automatically
Smart Event Creation
Auto-detect all-day events, smart alarms 15 minutes before
Time Update Sync
When you change a reminder's time in Aurely (snooze, edit), it automatically updates in Calendar
Visual Badges
Blue badge appears on all synced reminders (both imported and Aurely-created)
Smart Unsyncing
Unchecking badge in Edit dialog: imported events stay in Calendar, Aurely-created events are removed from Calendar

Setup Instructions

  1. Open Aurely → Settings → Integrations → Calendar Sync
  2. Toggle "Enable Calendar Sync" to ON
  3. Click "Grant Access" and allow Calendar access in the system dialog
  4. (Optional) Select your preferred calendar from the "Default Calendar" picker
  5. Configure sync direction: "Sync Reminders to Calendar" and/or "Import Calendar Events"
  6. When creating a reminder, tap the 📅 Calendar badge (blue) to sync it
💡 Pro Tip
Set reminders to 00:00 for all-day calendar events. Calendar notifications appear 15 minutes before timed events.

Todoist Integration

✅ Available Now Purple Badge

Two-way synchronization between Aurely reminders and Todoist tasks. Create reminders in Aurely and they appear as tasks in Todoist, or import today's tasks from Todoist into Aurely.

Features

Two-Way Sync
Sync reminders to Todoist and import tasks due today
Priority Mapping
Aurely priorities map to Todoist priorities (Low → Normal, Medium → High, High → Urgent)
Completion Sync
Completing in one app automatically completes in the other
Time Update Sync
When you change a reminder's time in Aurely (snooze, edit), it automatically updates in Todoist
Visual Badges
Purple badge appears on all synced reminders (both imported and Aurely-created)
Smart Unsyncing
Unchecking badge in Edit dialog: imported tasks stay in Todoist, Aurely-created tasks are removed from Todoist
Deep Linking
Todoist tasks include links back to Aurely reminders

Setup Instructions

  1. Get your Todoist API token: Todoist Settings → Integrations → Developer (or click "Get Token" in Aurely)
  2. Open Aurely → Settings → Integrations → Todoist Sync
  3. Toggle "Enable Todoist Sync" to ON
  4. Paste your API token into the "API Token" field (saved securely in Keychain)
  5. Configure sync direction: "Sync Reminders to Todoist" and/or "Import Todoist Tasks"
  6. When creating a reminder, tap the ✅ Todoist badge (purple) to sync it
💡 Pro Tip
Only tasks due today are imported - perfect for daily workflow. Tasks go to your default Todoist project.

Apple Reminders Integration

✅ Available Now Orange Badge

Two-way synchronization between Aurely reminders and Apple Reminders. Instant sync with reactive synchronization—changes happen immediately, no waiting for sync intervals.

Features

Instant Sync
Reactive synchronization - changes happen immediately
Two-Way Sync
Sync reminders to Apple Reminders and import from Apple Reminders
Completion Sync
Completing in one app automatically completes in the other
Time Update Sync
When you change a reminder's time in Aurely (snooze, edit via menu bar popover), it automatically updates in Apple Reminders
Visual Badges
Orange badge appears on all synced reminders (both imported and Aurely-created)
Smart Notifications
Aurely prevents duplicate notifications for synced reminders
Smart Unsyncing
Unchecking badge in Edit dialog: imported reminders stay in Apple Reminders, Aurely-created reminders are removed from Apple Reminders

Setup Instructions

  1. Open Aurely → Settings → Integrations → Apple Reminders Sync
  2. Toggle "Enable Reminders Sync" to ON
  3. Click "Grant Access" and allow Reminders access (on macOS 14.0+, choose "Full Access")
  4. (Optional) Select your preferred list from the "Default Reminder List" picker
  5. Configure sync direction: "Sync Reminders to Apple" and/or "Import Apple Reminders"
  6. When creating a reminder, tap the 🔔 Reminders badge (orange) to sync it
💡 Pro Tip
Instant sync means changes happen immediately - no waiting for sync intervals. Perfect for real-time workflow management.

How It Works

Simple, privacy-first integration workflow

1

Type or Record Your Reminder

Create a reminder using voice recording or text input in Aurely as usual.

2

Integration Badges Appear

When you start typing, integration badges (📅 Calendar, ✅ Todoist, 🔔 Reminders) appear above the text input—only if you have the integration enabled in Settings.

3

Tap Badges to Select

Tap the badges for services you want to sync with. Selected badges turn colored (blue, purple, or orange). Unselected badges remain outlined.

4

Create and Sync

Create the reminder as usual. After confirmation (when creation toast is confirmed), the reminder syncs to selected services automatically. Use Quick Actions in the menu bar to manage reminders instantly—snooze, edit time, or modify sync status.

🔒 Privacy Control
No badges = no sync: If you don't select any badges, the reminder stays only in Aurely. Nothing syncs unless you explicitly tap a badge. Complete control over your data.

Troubleshooting

Common issues and solutions

Integration badges not appearing

  • Verify integration is enabled in Settings
  • Ensure necessary permissions are granted
  • Check you've started typing a reminder

Sync not working

  • Verify both sync directions are enabled
  • Check sync interval hasn't expired (Calendar/Todoist)
  • Ensure reminder has a due date
  • Check network connection (for Todoist)

Permission issues

  • Go to System Settings → Privacy & Security
  • Ensure Aurely is listed and enabled
  • Try clicking "Grant Access" again in Aurely
  • On macOS 14.0+, choose "Full Access" for Reminders
